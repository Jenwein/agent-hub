# 备份

## 何时使用
主人要备份、要恢复、或每日 cron 触发。

## 输入
备份目标目录（默认 `~/backups/hub`），或要备份的资源和路径。

## 步骤
1. hub 状态：`bin/hub-backup [目标目录]`，会保留最近 30 份。
2. 主人的目录：在源机器上 `tar czf`，再 `scp` 到服务器或目标机器；路径从 `resources.yaml` 取。
3. 恢复：先把现有 `private/state` 移到 `tmp/` 再解包，不要直接覆盖。
4. 汇报文件路径和大小。

## 调用
- `bin/hub-backup`
- `tar`、`scp`

## 限制与需确认项
- 恢复会覆盖当前状态，属 L2，先确认。
- 备份包含账目和记忆，不要放到公开或共享位置。

## 完成判据
目标位置存在带日期的归档，`tar tzf` 能列出内容。
